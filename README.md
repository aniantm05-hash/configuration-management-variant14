# Эмулятор оболочки — вариант 14, этапы 1–2

Участник: Михайлова Анна Михайловна.

Окно Tkinter с заголовком `Эмулятор - [username@hostname]`.
Имена пользователя и компьютера берутся из ОС.
Ввод разделяется по пробелам. `ls` и `cd` — заглушки,
показывающие имя и аргументы. `cd` принимает не более одного аргумента.
`exit` без аргументов закрывает окно. Ошибки выводятся с `error:`.

## Запуск и тесты

Python 3.12 или новее с Tkinter. Сторонние библиотеки и сборка не нужны.
Из корня проекта на macOS/Linux:

```sh
sh run.sh
python3 -m unittest discover -s tests -v
```

На Windows: `run.bat`, тесты —
`python -m unittest discover -s tests -v`.

## Пример

В окне введите `ls`, `ls /docs`, `cd /docs`, `cd a b`, `unknown`, `exit`.
Первые команды показывают аргументы, затем выводятся ошибки,
последняя команда закрывает окно.

## Настройки и стартовый скрипт

`--vfs PATH` задаёт путь будущей VFS; на этапе 2 загрузки ещё нет.
`--script PATH` задаёт стартовый файл UTF-8 с командами.
`--batch` выполняет скрипт без окна. `--help` показывает справку.
При запуске выводятся все параметры. Пути относительны рабочей папке.

Комментарии с `#` вне кавычек пропускаются. Ввод и вывод показываются.
Ошибка содержит номер строки; выполнение продолжается.
`exit` прекращает скрипт. Код процесса: 0 — успех,
1 — ошибка чтения/выполнения скрипта, 2 — неверные параметры запуска.

```sh
sh run.sh --vfs sample --script examples/stage2.txt --batch
sh scripts/stage2.sh
```

## Функции и документация

`interface.py` — окно и ввод; `shell.py` — выполнение и ошибки;
`parsing.py` — разбор строки; `main.py` — запуск.
`config.py` — параметры; `startup.py` — стартовый скрипт.
Описание всех функций: [docs/API.md](docs/API.md).
