# Проверка этапов 1–3

На Python 3.12.14 в Linux:

- 21 автоматический тест пройден.
- `sh run.sh --help` работает.
- `sh scripts/stage2.sh` и `sh scripts/stage3.sh` завершаются с кодом 0,
  проверяя успешные и ошибочные запуски.
- Доступны ровно `ls`, `cd`, `exit`, `vfs-info`, `vfs-init`.
- `ls` и `cd` сохраняют поведение заглушек.
- Проверены три структуры VFS, байты файлов, хеш и сброс источника.
- Python-строки не длиннее 80 символов; функции не длиннее 40 строк.

GUI проверяется с подменой виджетов. Реальное окно на Mac
нужно показать при ручном запуске.
