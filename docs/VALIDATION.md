# Проверка этапов 1-5

На Python 3.12.14 в Linux пройдены 34 автоматических тестов.
Проверены основные команды, режимы, ошибки путей и аргументов,
байтовый подсчёт wc и отсутствие изменений в папке-источнике.
Сценарий stage4 проверяет успешный запуск и код 1 при ошибках команд.

GUI проверяется с подменой виджетов в тестах. Реальное окно нужно
показать на компьютере при ручном запуске.

Проверены chown, рекурсивный сброс владельца, сохранность источника
на диске и отсутствие частичных изменений при ошибке пути.
