# Демонстрация первых трёх этапов

Текущая версия включает окно, заглушки `ls` и `cd`, `exit`,
параметры запуска, стартовые скрипты и VFS с двумя служебными командами.
Ручные команды приведены в README.

На macOS/Linux: `sh scripts/stage2.sh`, затем `sh scripts/stage3.sh`.
Сценарии создают учебные папки и проверяют ожидаемые коды процесса.
Этап 3 проверяет три структуры VFS и сброс учебного источника.

## Отдельные версии

Для проверки ранних этапов используйте папки stage1 и stage2
из архива с учебными версиями. Скрипты этапа 2 в текущей версии
используют существующую учебную папку VFS.
