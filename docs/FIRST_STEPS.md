# Первый запуск

Распакуй архив. Открой приложение «Терминал».
Напечатай `cd ` с пробелом, перетащи папку проекта в Терминал
и нажми Enter. Так ты перейдёшь в папку проекта.

```sh
python3 --version
python3 -m tkinter
```

Нужен Python 3.12 или новее. Вторая команда должна открыть окно Tkinter.
Закрой тестовое окно и выполни:

```sh
python3 -m src.fixtures
sh run.sh --vfs .generated/deep
```

В эмуляторе введи `ls`, `cd /docs`, `vfs-info`, затем `exit`.
`ls` и `cd` печатают свои имена и аргументы: это заглушки по условию.
`vfs-info` показывает сведения о загруженной файловой системе.

Git хранит сохранённые версии проекта. Коммит — набор изменений
с сообщением, тег — имя определённой версии. `.git` хранит историю.
В проекте есть три этапа; `git log --oneline` показывает их коммиты.
GitHub — сайт, на котором можно опубликовать репозиторий.

Для сдачи нужен публичный репозиторий, ссылка на него и PDF README.
После публикации открой README на сайте, нажми Cmd+P на Mac
и выбери сохранение в PDF. ZIP в репозиторий не добавляется.
