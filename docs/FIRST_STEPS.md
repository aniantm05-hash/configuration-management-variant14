# Первый запуск

Откройте Терминал и перейдите в папку проекта командой `cd`.

```sh
python3 -m src.fixtures
python3 -m src.main --vfs .generated/deep
```

Команды вводятся в нижнюю строку окна эмулятора, по одной.
Начните с `ls`, `cd /docs`, `ls`, `cd`, `who`, затем `exit`.
Режимы команд и дополнительные примеры приведены в README.
